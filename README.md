# Java & Python DSA

This repository is a structured collection of Data Structures and Algorithms practice problems solved in both Java and Python. The goal is to improve problem-solving ability, strengthen algorithmic thinking, and prepare for technical interviews and coding assessments.

## Repository Structure

Each topic is organized into its own folder and then split by language:

- `01-Arrays`
- `02-Strings`
- `03-Hashing`
- `04-Sorting`
- `05-Binary-Search`
- `06-Linked-List`
- `07-Stack`
- `08-Queue`
- `09-Recursion`
- `10-Backtracking`
- `11-Binary-Tree`
- `12-BST`
- `13-Heap`
- `14-Greedy`
- `15-Dynamic-Programming`
- `16-Graphs`
- `17-Trie`

Inside each topic folder, solutions are organized as:

- `Java/`
- `Python/`
